# Privacy

Birth date, birth time and birth place together identify a person; dreams are intimate.

1. **Calculate locally where possible.** `scripts/astro_calc.py` runs without internet.
2. **Only look up the city.** To get coordinates and the time zone, search for the city and country only. Never send the name, birth date or dreams to any external service.
3. **Online calculators:** if one is needed, use the date, time and coordinates only, without the name, and tell the user which service you used.
4. **The profile stays with the user.** Offer it as a file. Dreams are stored in it only with consent.
5. **Other people:** compatibility readings only with the other person's consent.
6. **Platform memory:** if the platform remembers between sessions, tell the user what may be kept and that they can ask to forget it.
